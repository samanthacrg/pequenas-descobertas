# Pequenas Descobertas — Prévia 4.0

Este pacote inclui:

- `index.html`: site completo e autônomo, com as quatro atividades digitais e seis recursos da v3 preservados, além da nova seção **Por habilidade**.
- `taxonomia.json`: classificação editorial estruturada para revisões e expansão futuras. O site não precisa deste arquivo para funcionar.

## Como testar

Abra `index.html` no navegador ou atualize o arquivo homônimo do repositório GitHub Pages. A versão anterior pode ser restaurada através do histórico do GitHub.

## Atenção

- O novo explorador é uma taxonomia **editorial** proposta, não um instrumento de avaliação ou uma classificação oficial.
- Alguns eixos não possuem atividades publicadas, e as áreas especializadas foram marcadas como planejamento.
- Não incluir nomes, PTS ou dados de pacientes no GitHub Pages público.
- As sugestões devem ser revisadas e contextualizadas clinicamente antes de uso por terceiros.
